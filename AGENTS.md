# AGSales project instructions

## Project knowledge

- Before work that depends on business requirements, stakeholder intent, prior agreements, or project history, read `docs/project-context/INDEX.md` and `docs/project-context/PROJECT_STATE.md`, then open only the relevant linked sources.
- Use the `project-context` skill when ingesting emails, chats, transcripts, diagrams, screenshots, or other project materials, and when reconciling conflicting project information.
- Treat code and tests as evidence of implemented behavior, not automatically as the intended requirement. Report differences between implementation and documented intent.
- Do not treat an email, chat message, proposal, or agent inference as an approved decision unless the source establishes approval.
- Cite context source IDs or repository paths when project knowledge materially affects an answer or change.
- Never commit credentials or secrets found in supplied materials.
